# ML Reports Directory

This folder stores model evaluation summaries, training curves, confusion matrix plots, and validation reports generated during model training and evaluation runs.

## Expected Artifacts
- `evaluation_results.json`: Machine-readable metrics (Accuracy, Macro-F1, Macro-Precision, Macro-Recall, Per-Class breakdown).
- `confusion_matrix.png` & `confusion_matrix.json`: Detailed class confusion metrics.
- `model_evaluation_report.md`: Student & hackathon reviewer-friendly report detailing dataset, architecture, hyperparameters, and results.
- `training_history.json`: Epoch-by-epoch training and validation loss and accuracy curves.
